# Saphi

Conjugador de verbos quechuas. Escribes un verbo en infinitivo, por ejemplo `takiy`, y te muestra sus formas divididas en raíz, sufijos, tiempo y persona.


## Qué hace

- Conjuga en indicativo, potencial, imperativo y formas no personales (infinitivo, participios y gerundio).
- Incluye la voz pasiva.
- Permite añadir sufijos derivativos (`-ku`, `-chi`, `-ri`, `-mu`…), hasta tres.
- Al tocar una forma muestra de qué partes está hecha. Por ejemplo, `takirqani` = `taki` + `-rqa` + `-ni`.


## Archivos

- `index.html`: la página
- `style.css`: los estilos
- `app.js`: las terminaciones, los sufijos, la lista de verbos y el código que conjuga

## Fuente

*Gramática Quechua*, de Alfredo Quiroz Villarroel (2000). La herramienta puede ser mejorada y no cubre todas las variedades del quechua.
